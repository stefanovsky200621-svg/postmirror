# POSTMIRROR

Сайт для оформления заявки на зеркало в стиле Instagram-поста.

Основная документация: [карта проекта](PROJECT_MAP.md). В ней описаны файлы, настройки, сценарий заказа и порядок проверки изменений.

## Быстрый запуск

```sh
npm ci
npm run dev
```

Нужен Node.js 22.13 или новее. Адрес локального сайта выводится после запуска.

## Проверка перед обновлением

```sh
npx tsc --noEmit
npx oxlint app/page.tsx app/layout.tsx
npm run build
```

Для просмотра собранного сайта: `npm run start`.

Заказ отправляет сам покупатель: сайт формирует текст и предлагает скопировать его, затем перейти в Telegram или Instagram.
